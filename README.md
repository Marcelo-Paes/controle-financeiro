# 💰 Controle de Finanças Pessoais

Aplicação web desenvolvida para facilitar o gerenciamento das finanças pessoais. Com ela, é possível registrar salário, gastos e economias de forma simples e visual, com os dados organizados por mês e por ano. A aplicação também oferece autenticação de usuários e persistência em nuvem com Firebase.

## 🚀 Funcionalidades

- Cadastro e autenticação de usuários com Firebase Authentication
- Registro de salário mensal
- Adição e exclusão de **gastos** e **economias**
- Resumo anual com:
  - Total economizado
  - Total gasto
  - Saldo final
- Dados organizados por **mês** e agrupados por **ano**
- Interface moderna com atualização em tempo real
- Armazenamento persistente com Firebase Firestore

## 🛠️ Tecnologias Utilizadas

- **HTML**  
- **CSS**  
- **JavaScript (Vanilla)**  
- **Firebase Authentication**  
- **Firebase Firestore**
